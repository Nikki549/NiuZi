# 个人作品集

小和的个人作品集网站，用于集中展示个人介绍、技能方向与项目作品。使用原生 HTML、CSS 和 JavaScript 编写，无构建步骤，克隆后可直接在浏览器中打开。

## 功能

- 左侧固定个人栏：头像、姓名、简介、技能方向与站内导航
- 右侧内容区：项目作品、关于我、联系方式
- 项目作品按时间顺序展示，图文交替排版，支持移动端单列布局
- 滚动时自动高亮当前所在区块的导航项
- 深浅色主题切换：按钮位于左侧栏顶部右侧，选择通过 `localStorage` 记忆，刷新后保持

## 目录结构

```
lab04/
├── index.html          # 页面结构
├── profile.md          # 个人资料原始文本，data.js 的数据来源
├── css/
│   ├── base.css        # 设计变量（含深浅色主题变量）、重置样式、基础排版
│   ├── layout.css      # 左右分区结构、粘性侧栏、响应式布局
│   └── components.css  # 个人信息、导航、标签、项目条目、关于我、联系方式
└── js/
    ├── data.js         # 页面内容数据（个人信息、项目、联系方式）
    ├── render.js       # 根据 data.js 渲染页面
    ├── theme.js        # 深浅色主题切换
    └── main.js         # 导航高亮、锚点滚动、内容进场淡入
```

## 本地运行

由于页面通过 `<script src>` 加载脚本、通过相对路径引用样式和图片，建议使用本地服务器打开（直接用 `file://` 打开也可以，但服务器方式更接近线上环境）：

```bash
# 任选一种
python -m http.server 5173
npx serve .
```

然后在浏览器访问 `http://localhost:5173/`。

## 维护说明

新增或修改项目、联系方式等展示内容时，只需编辑 `js/data.js`：

- `PROFILE`：个人信息与技能方向
- `PROJECTS`：项目作品数组，追加一个对象即可新增项目
- `CONTACTS`：联系方式，`href` 为空时渲染为不可点击的文本

## 技术说明

- 原生 HTML / CSS / JavaScript，不使用 React、Vue 等框架，不引入第三方 UI 组件库
- 使用 CSS 变量管理颜色与尺寸，深浅色主题通过 `<html>` 上的 `data-theme` 属性切换
- `theme.js` 在 `<head>` 中同步加载，在首次渲染前确定主题，避免刷新时闪白
- 布局基于 CSS Grid 与 Flexbox，兼容桌面端与移动端（断点 1100px / 860px）

## 部署

网站为纯静态站点，通过 GitHub Pages 部署：仓库 `Settings → Pages` 中将 Source 设为 `Deploy from a branch`，Branch 选择 `main`、目录选择 `/(root)`，保存后访问 `https://<用户名>.github.io/<仓库名>/`。

## 开发过程

本项目在实验三完成的个人作品集网站基础上迭代：先初始化 Git 版本管理并提交基线，再新增深浅色主题切换功能，在浏览器中验证通过后提交，最后推送到 GitHub 并部署到 GitHub Pages。
